# QA Rule Verification
## Do
- Start from the official rule or Q&A text.
- Add the smallest test that proves the rule.
- Update the verification note or matrix when the result changes.
## Do not
- Do not keep stale research in the skill.
- Do not create a test without the exact rule in view.
## Verify
- Run the focused test and compare the result to the ruling.
