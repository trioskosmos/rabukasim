# Ability Data Flow

This folder keeps the authored ability source separate from the compiled runtime data.

## Source of truth

- `data/ability_frame_source.json` is the authored, text-first semantic ability source.
- `data/cards_compiled.json` is the compiled runtime card database that stores executable `abilities[].frame_program.frames[]`.

## Build flow

1. The compiler reads `data/cards.json` as the raw card database.
2. It compiles the raw cards into `data/cards_compiled.json`.
3. The build pipeline can mirror compiled runtime assets into the launcher and engine copies.
4. The authored source file is edited directly and is no longer regenerated by the build.

## What belongs where

- `data/ability_frame_source.json`
  - `primary_text_jp`
  - `primary_text_en`
  - `source_ability_texts`
  - `trigger_id`
  - `trigger`
  - `frames`
  - `card_refs`
  - authored flags such as `choice_flags`, `choice_count`, `is_once_per_turn`, `requires_selection`
- `data/cards_compiled.json`
  - compiled runtime card data and per-card frame programs
- `data/ability_frame_issues.md`
  - diagnostics and discrepancy triage only
