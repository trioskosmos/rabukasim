# Rust Test Explorer
## Do
- Find the exact test name first.
- Run the smallest useful filter.
- Capture output when investigating failures.
## Do not
- Do not launch the full suite unless broad confirmation is needed.
- Do not guess at a test path or module name.
## Verify
- Confirm the filtered test appears in output and finishes cleanly.
