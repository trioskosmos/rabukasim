# Card ID Mapping
## Do
- Resolve by card number first.
- Confirm the logic ID against the current mapping file.
- Note legacy aliases only when they still matter.
## Do not
- Do not invent IDs from similar names.
- Do not mix old numbering with current logic IDs.
## Verify
- Make sure the resolved ID matches compiled data.
