# Card Data
## Do
- Use the card database or cf.py as the source of truth.
- Cross-check card no., logic ID, name, and group before editing tests.
- Prefer current compiled data over archived mappings.
## Do not
- Do not guess IDs from memory.
- Do not mix legacy labels with current logic IDs.
## Verify
- Confirm the card number, logic ID, and source row in data.
