# Robust Editor
## Do
- Preserve formatting and line endings.
- Prefer focused, minimal patches.
- Check the result after editing.
## Do not
- Do not rewrite unrelated sections.
- Do not use broad replace when a small patch works.
## Verify
- Re-open the file or check the diff after the edit.
